# GRAFF CREA — Estudio creativo

Web corporativa de GRAFF CREA desarrollada con React y Vite. Sitio en español, con dirección de arte editorial, portfolio conceptual, servicios, presentación del estudio y contacto.

## Desarrollo local

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

## Publicación
El proyecto está preparado para despliegue en Vercel o Netlify. Configuración:
- Framework: Vite
- Build command: `npm run build`
- Output directory: `dist`

## Antes del lanzamiento comercial
- Los cuatro proyectos del portfolio son conceptuales y deben seguir identificados como tales hasta ser sustituidos por trabajos reales.
- El correo hola@graffcrea.com es provisional y debe activarse antes de publicar el contacto.
- El formulario de contacto no envía datos: se utiliza un enlace de correo electrónico.
- Añadir aviso legal, privacidad y cookies cuando proceda.
- Verificar disponibilidad del dominio y registro de marca.
- Revisar licencias de tipografías y recursos externos.
